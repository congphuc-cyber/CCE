📋 Hướng dẫn

  1. Xuất file CSV từ Google Form (Phản hồi → Xuất sang Sheets → Tải về dạng CSV).
  2. File cần có các cột: Tên đợt thi, Họ và tên, Số CCCD/CMND; cột Số điện thoại không bắt buộc.
  3. Chọn đợt thi tương ứng rồi kéo thả file để tải lên.
  4. Hệ thống sẽ kiểm tra từng dòng. Nếu có lỗi, không dòng nào được lưu — sửa file và tải lại.
